# Голоса для озвучки

## Что есть локально (Silero v5, `voices/v5_ru.pt`)

| Голос | Тембр | Замечания |
|---|---|---|
| `eugene` | мужской, средний | по умолчанию; ровно, но дикция чуть «машинная» |
| `aidar` | мужской, ниже | в v5 звучит нейтральнее, чем в v4; в ролике ускорен на 10% (`--speed 1.1`) |
| `baya`, `kseniya`, `xenia` | женские | артикуляция чище мужских, для объясняющего контента читается легче |

Генерация:

```bash
python3 src/tts_silero.py --speaker aidar --model voices/v5_ru.pt --out audio_aidar --speed 1.1
bash make_voice.sh aidar          # пересобрать ролик этим голосом
```

## Голос автора (лучший вариант)

Записать 11 фраз подряд с паузами ~1 с, затем:

```bash
python3 src/split_voice.py запись.ogg --expect 11 --out audio_user
bash make_voice.sh user
```

`split_voice.py` режет по `silencedetect`, проверяет, что фраз ровно 11, обрезает края,
гасит тихий шум и нормирует пик. Если фраз не 11 — падает, а не собирает видео на кривых таймингах.

## Чего на этой машине нет

- **XTTS v2 (клонирование по записи)** — модели нужно ~4 ГБ RAM, у сервера 1.9 ГБ: процесс убивает OOM.
  Плюс лицензия CPML запрещает коммерческое использование.
- **edge-tts (Microsoft Dmitry)** — с этого IP 403; на ru-vm работает нестабильно (половина фраз приходит пустой).
- **Yandex SpeechKit** — не подключён: нужен ключ Yandex Cloud (сервисный аккаунт, роль `ai.speechkit-tts`)
  и folder id. Даёт студийное качество и легальное клонирование голоса, стоит копейки.
